# 美叽和大鼠角色与桌宠动作规范

本规范用于非商业的 Codex 主题与桌宠制作。视觉素材优先直接采用作者公开发布的官方表情包与短篇动画帧，不重新设计角色五官、体型或配色。转载与分享须注明作者“砂糖仙贝 / 美叽和大鼠”，禁止商用。

## 共同视觉规则

- 保留粗黑轮廓、扁平上色、圆润短肢和夸张眼神。
- 禁止写实毛发、立体渲染、玻璃高光、渐变塑料感和通用 AI 萌系五官。
- 每个桌宠只显示一个角色；角色接力时切换整只宠物，不把三只拼成一个图集画面。
- 原图有道具时只保留与状态相符且不含可读品牌文字的道具。
- 动画优先使用官方 GIF 或短篇连续帧。缺帧时只允许克制的呼吸、眨眼、轻微位移，不改脸型。

## 大鼠

- 外形：灰色圆鼠，粉色圆耳，短手短脚，黑色粗线，眼神变化幅度大。
- 气质：打工感、反应直接、偶尔疲惫和疑惑，但仍会认真做事；可活泼，不塑造成精明强势角色。
- 合适动作：挥手、疑惑、冒汗、电脑前工作、举便签、探头、开心大笑、害羞、叹气、鞠躬。
- 状态建议：待机用闭眼或微笑；运行用电脑/举手；等待用疑惑或探头；失败用冒汗；完成用星星眼或大笑。

## 美叽

- 外形：白色圆团身体，黑色双辫状耳发，红色蝴蝶结，明显腮红，小脚。
- 气质：娇俏、讲究、表情丰富，有一点小傲娇但不刻薄；可爱来自原作神态，不靠幼儿化。
- 合适动作：挥手、侧躺、惊讶、思考、双手合十、闪亮期待、举手、电脑前工作、写便签、害羞、倾听、鞠躬。
- 状态建议：待机用端坐或侧躺；运行用电脑/写便签；等待用合十或倾听；失败用冒汗；完成用闪亮期待或挥手。

## 旺财

- 外形：黄色圆润小狗，奶白色大口鼻与肚皮，小卷耳，黑色粗线，短尾短腿。
- 气质：热情、憨萌、可靠地陪伴，反应直白；不塑造成凶犬、酷帅角色或过度幼稚的宠物狗。
- 合适动作：挥手、坐下、惊讶、思考、害羞、睡觉、得意、星星眼、加油、电脑前工作、写便签、探头、大笑、倾听、鞠躬。
- 状态建议：待机用坐下或睡觉；运行用加油/电脑；等待用疑惑或倾听；失败用冒汗；完成用星星眼或大笑。
